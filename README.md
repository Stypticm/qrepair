# QOQOS — Веб-платформа для сервиса по выкупу и продаже техники

Пет проект который вырос видимо в стартап. Пишу в соло, совмещая обучение и реальную разработку.

Идея простая: автоматизировать всю рутину небольшого сервиса по скупке, ремонту и перепродаже смартфонов. Клиент оставляет заявку онлайн, ИИ-агент помогает оценить устройство, менеджер получает уведомление в Telegram. Никаких Excel-таблиц и бесконечных созвонов.

## Что умеет

- Онлайн-скупка устройств с оценкой состояния
- Маркетплейс восстановленной техники
- Заявки на ремонт с отслеживанием статуса
- Чат с ИИ-ассистентом (Ollama, локальная модель)
- Административная панель для менеджеров
- Trade-in форма

## Стек

**Frontend:** Next.js 15, TypeScript, Zustand, CSS Modules  
**Backend:** Go (chi), PostgreSQL, Qdrant (векторная БД), Ollama  
**Инфраструктура:** Docker Compose, N8N (автоматизация), Telegram Bot API  
**Деплой:** Vercel (frontend)

> Backend вынесен в отдельный приватный репозиторий.

## Запуск локально

```bash
# Установить зависимости
npm install

# Создать .env.local на основе .env.example
cp .env.example .env.local

# Запустить dev-сервер
yarn dev:https
```

Для полноценной работы нужен запущенный backend (Docker Compose).
